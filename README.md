# Atharv Sawant — Tinkercad Electronics Portfolio

A professional portfolio for Atharv Sawant's Arduino and Autodesk Tinkercad work.

## Portfolio structure
- 2 integrated project showcases (private Tinkercad builds)
- 5 public Tinkercad simulations with direct links
- Arduino source-code viewers for the public simulations
- Technical skills and project progression sections

## Integrated projects
1. Smart Access & Automation System
2. Smart Obstacle-Aware Motor Control

These two projects are intentionally presented without public Tinkercad links.

## Public simulations
- Blink LEDs
- Traffic Light Controller
- 4-Bit LED Loop
- Manually Controlled LED
- Music-Controlled Dancing LEDs

## Run locally
Open `index.html` in a browser. For the code viewer to work reliably, serve the folder with a local web server (for example, VS Code Live Server).

## Deploy
The folder can be hosted on GitHub Pages, Netlify, Vercel, or Firebase Hosting.
